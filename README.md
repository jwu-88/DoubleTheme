# DoubleTheme
DoubleTheme is a clean, modern, and user-friendly CSS theme designed to elevate your Discord experience. It features a sleek aesthetic, refined color palettes, and optimized layouts that make chatting, browsing servers, and hanging out in voice channels smoother and more visually appealing.

## How to Install

Depending on which Discord client mod you are using, follow the appropriate set of instructions below.

### Option 1: Installing on BetterDiscord

1. **Download the Theme File:** Ensure you have the `doubletheme.css` file saved somewhere easily accessible on your computer.
2. **Open BetterDiscord Settings:** Open Discord, go to **User Settings** (the gear icon near your username), and scroll down to the **BetterDiscord** section in the left sidebar.
3. **Open the Themes Folder:** Click on **Themes**, then click the **Open Themes Folder** button at the top. This will open your File Explorer/Finder.
4. **Move the Theme:** Drag and drop your downloaded `doubletheme.css` file directly into this `themes` folder.
5. **Enable the Theme:** Head back to Discord, and you should now see **DoubleTheme** appear in your list of themes. Toggle the switch to **On** to apply it!

### Option 2: Installing on Vencord

1. **Download or Copy the Theme:** Locate your `doubletheme.css` file or the raw CSS code. 
2. **Open Vencord Settings:** Open Discord, go to **User Settings**, and look for the **Vencord** section in the left sidebar.
3. **Navigate to Themes:** Click on **Themes** under Vencord.
4. **Add the Theme:** 
   * **Local File/Folder Method:** If Vencord is pointed to a custom themes folder, drop your `doubletheme.css` file into that designated directory.
   * **Quick Snippet Method:** Alternatively, click on **Online Themes** or use the **Custom CSS** tab in Vencord to paste your CSS code directly into the editor.
5. **Enable the Theme:** Toggle the switch next to DoubleTheme to activate it instantly.
